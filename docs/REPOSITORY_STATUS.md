# Repository status and evidence boundaries

This is a curated **archived university capstone** repository based on the team's original files, project report, hardware photos, and demonstration. The original archives contain duplicate and alternative versions of some sources.

- Primary firmware and Raspberry Pi source selection: [`CODE_SELECTION.md`](CODE_SELECTION.md).
- Alternate ESP source and communications differences: [`ESP_REVISION_AUDIT.md`](ESP_REVISION_AUDIT.md).
- Source-versus-report claims: [`REPORT_TO_CODE_DISCREPANCIES.md`](REPORT_TO_CODE_DISCREPANCIES.md).
- Historical physical demonstration versus fresh test evidence: [`TESTING.md`](TESTING.md).
- Outstanding reproducibility and safety issues: [`KNOWN_LIMITATIONS.md`](KNOWN_LIMITATIONS.md).

The hardware was demonstrated by the original team; the curated repository has not undergone a fresh integrated physical test. No new performance measurements have been made, no third-party code/media licenses have been re-assigned, and the original full report is not distributed in this repository.
