# Repository preparation notes — archived capstone

- Curated Raspberry Pi, Arduino and ESP source files plus the stand-alone web interface.
- Fritzing circuit design, as-built component summary and engineering documentation.
- Hardware photo gallery, animated README preview, full ~77-second recording and shorter excerpt.

## Verification scope

Python files parsed and file/link/configuration checks run in the preparation environment. Arduino/ESP compilation, GPIO and motor behavior, and MQTT/HTTP end-to-end operation have **not** been independently validated with the original prototype.

This is a historical university mechatronics capstone portfolio, **not** a software-only chess game or a turnkey hardware kit.
